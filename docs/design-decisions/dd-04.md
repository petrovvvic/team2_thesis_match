## DD-01: Kombinierte Suche und Filterung im Professor-Feed

### Meta

Status
: Decided

Updated
: 23-Jun-2026

### Problem statement

Wie sollen Studierende im Professor-Feed nach einem passenden Betreuer suchen können?

Der Feed zeigt alle Professorinnen und Professoren des Fachbereichs an. Studierende sollen die Liste gezielt eingrenzen können, zum Beispiel nach Name, Themengebiet, Facheinheit oder Verfügbarkeit.

Dabei mussten wir zwei Entscheidungen treffen:

* Soll die Suche über mehrere getrennte Felder oder über ein zentrales Suchfeld erfolgen?
* Soll die Filterung direkt in der Datenbank oder im Python-Code stattfinden?

### Decision

Wir verwenden ein Freitext-Suchfeld für Namen und Themengebiete sowie zwei zusätzliche Filter für Facheinheit und Verfügbarkeit.

Die Professorenprofile werden zunächst geladen und anschließend im Python-Code gefiltert. Da die Anzahl der Professor:innen überschaubar ist, bringt eine komplexere Datenbankabfrage für unseren Anwendungsfall keinen wesentlichen Vorteil. Die Suche berücksichtigt sowohl den vollständigen Namen als auch die hinterlegten Themengebiete.


*Decision was taken by:* Aya Madarati

### Regarded options

Wir haben zwei Alternativen betrachtet:

* Option A: Filterung direkt in der Datenbankabfrage
* Option B: Laden aller Profile und anschließende Filterung in Python

| Kriterium               | Option A: Datenbank-Filter                | Option B: Python-Filter                |
| ----------------------- | ----------------------------------------- | -------------------------------------- |
| Performance             | ✔️ Nur passende Datensätze werden geladen | ❌ Alle Profile werden zunächst geladen |
| Implementierungsaufwand | ❌ Komplexere Query-Logik                  | ✔️ Einfach umzusetzen                  |
| Lesbarkeit              | ❌ Schwerer nachvollziehbar                | ✔️ Gut lesbar                          |
| Wartbarkeit             | ❌ Änderungen an der Query notwendig       | ✔️ Filterlogik zentral im Code         |

Da nur eine begrenzte Anzahl an Professoren verwaltet wird, haben wir uns für Option B entschieden.
